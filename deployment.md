# Deployment

## Scope

Restructure 1.0 is deployed by Git checkout and local marketplace
installation. There is no hosted production endpoint, public directory
listing, account service, database, or remote runtime to deploy.

## Release preparation

From a clean checkout:

    npm install
    npm test
    npm run validate
    cd mcp
    npm install
    npm test

Inspect that these release surfaces all contain version 1.0.0:

- .codex-plugin/plugin.json
- package.json
- mcp/package.json
- mcp/package-lock.json root package entry
- mcp/src/create-server.ts

Ensure mcp/dist contains the standalone runtime and UI resource generated by
the MCP build. Include those artifacts in the Git commit used by consumers.
The repository marketplace source path in
.agents/plugins/marketplace.json must resolve to the registered repository
root and remain inside that root.

## Consumer installation

Consumers clone or check out the Git repository, register its repository root
as a local marketplace source with their Codex host, install
restructure@restructure-repo, restart the host, and start a new
conversation. ChatGPT desktop installation depends on the app's local
marketplace flow and remains a host check rather than a repository deployment.

## Rollback

To roll back, select a known-good Git commit, rebuild mcp/dist, and reinstall
the plugin from that checkout. Start a new host conversation after rollback.
There is no server state or database migration to reverse. Any Project
Instructions or AGENTS.md snippet is repository/host-owned text and must be
reverted through its normal owner.

## Operational boundary

Do not add credentials, API keys, OAuth configuration, hosted endpoints,
production data, or background workers for this local release. Native host
permissions and confirmations remain active after prompt approval.
